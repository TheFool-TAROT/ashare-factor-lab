# 日频横截面选股因子评估

> 自动生成 · 外样本 480 个交易日 / 8 折 · 样本 171,153 行 / 160 只股票（含退市 19 只）
> 数据来源：合成数据（带已知反向动量信号，用于验证流水线能把它检出来）

## 1. 结论

> 信号存在但被成本淹没：毛超额 0.0797% / 日，成本 0.2053% / 日，扣费后 -0.1256% / 日。
> 随机选股对照 p=0.000，策略落在随机分布的 100.0% 分位（显著优于瞎选）。
> 稳定性：8/8 折为正，最差折 RankIC 1.9671%；换手 69.1% / 日 —— 换手是这个策略的第一约束。

## 2. 方法（口径先行）

| 项 | 设置 |
|---|---|
| 标签 | t 日收盘出信号 → **t+1 开盘买 → t+1+1 开盘卖**（`fwd_ret = open[t+1+1]/open[t+1]-1`，默认持有 1 日） |
| 切分 | walk-forward，训练 500 日 / 测试 60 日 / 步长 60 日 / embargo 2 日 |
| 可交易性 | 流动性 + 上市天数 + ST 代理 + 交易日连续性 + t+1 涨停买不进 + t+2 跌停卖不出 |
| 头部组 | 每日按预测分取前 10% |
| 成本 | 佣金 2.50bp/边 + 过户费 0.10bp/边 + 印花税 5bp(卖出) + 半价差 10bp/边 |
| 随机对照 | 同宇宙同规模随机选股 300 次 |

注意 `no_quote_after` 一行：这些行不是没有信号，而是**没有价格可观测**（退市、长期停牌），
通常对应急跌。上游版本用 `dropna` 把它们整行删掉，等于用「未来可得性」筛样本，
会系统性高估收益、低估回撤。本框架把这类行单独计数并暴露出来，
绝对收益口径下应按保守假设（持有至清算价）入账，而不是静默丢弃。

## 7. 局限（不写这一节的研究不值得信）

1. **时点成分股不可得**：宇宙是「当前成分股 + 样本期内退市股」，不是真正的历史成分。
2. **ST 是代理不是公告口径**：用 5% 停板特征推断，会有漏判与误判。
3. **滑点是假设**：没有盘口/逐笔数据，用 5/10/20bp 三档做敏感性，真实值取决于资金量与冲击成本。
4. **未做行业/市值中性化**：模型可能部分在赌行业轮动，这部分收益不稳健。
5. **未考虑涨停板排队**：开盘价成交的假设在极端行情下偏乐观。
6. **多重检验**：持有期等超参是扫过的，DSR 已做修正，但不排除仍有未记录的试错。
