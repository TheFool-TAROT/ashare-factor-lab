## 一、30 秒结论

| 结论 | 证据 |
|---|---|
| **信号是真的**（外样本、非过拟合假象） | RankIC **1.69%**，IC_IR 0.096，8/8 折同号，随机选股对照落在 100% 分位 |
| **但它赚不到钱** | 毛超额 **0.094%/日** vs 成本 **0.206%/日**（10bp 半价差）—— 成本是毛收益的 **2.2 倍** |
| **所以正确结论是"不做"** | 扣费后年化超额 −24.5%；同宇宙等权基准净值 1.821，策略 0.896 |

> 这个项目最有价值的部分不是"AI 能预测股价"，而是**一套能证明"不能"的评估框架**：
> 未来函数、生存偏差、成本造假这三件事，都做成了可自动检验的对象 ——
> 因为因子研究里 90% 的错误结论都出在这三处，而不是出在模型不够强。

**一条命令复现全部结论**（不需要任何真实行情数据）：

```bash
git clone https://github.com/TheFool-TAROT/ashare-factor-lab && cd ashare-factor-lab
pip install -e ".[dev]"
make demo          # 合成数据跑完整流水线，约 3 分钟，输出 docs/demo_report.md 同款报告
make test          # 58 个测试，含"篡改未来数据、断言历史特征不变"的因果性测试
```

## 二、这个仓库解决什么问题

量化因子研究里，一个"看起来很成功"的结论通常死于三件事之一：

| 死因 | 典型症状 | 本框架的对策 | 对应测试 |
|---|---|---|---|
| **未来函数** | 特征里混进了 t 日之后的信息，回测漂亮、实盘归零 | 全部特征只用 trailing 窗口；**扰动测试**：把 t 之后所有行情改掉，重算后断言第 t 行特征逐列不变 | `tests/test_causality.py`（4 个） |
| **生存偏差** | 只用"今天的成分股"回溯，退市股被悄悄剔除，IC 被抬高一半 | 宇宙显式携带退市标记与真实上市日期；同一套特征只切换是否纳入退市股，量化差异 | `tests/test_universe_baselines.py` |
| **成本假装不存在** | 只报毛超额，不报换手与滑点；日频调仓的高换手被忽略 | 成本模型按券种规则逐项拆开（佣金/过户费/印花税/三档滑点），并把"盈亏平衡换手"算出来 | `tests/test_costs_backtest.py` |

外加两件常被省略的事：**统计显著性**（Newey-West t、Bootstrap、Deflated Sharpe）与**公平基准**（同宇宙、同过滤、同测试日的等权对照 + 随机选股分布）。

## 三、方法（口径先行，否则数字没有意义）

| 项 | 设置 | 为什么必须这样 |
|---|---|---|
| 标签 | t 日收盘出信号 → **t+1 开盘买入 → t+1+h 开盘卖出**（默认 h=1，即 t+2） | A 股 T+1；用 t 日收盘价买入在时点上不可执行 |
| t+1/t+2 判定 | 必须是**市场日历上的下一个交易日**，不只是"存在下一行" | 中途停牌的股票"下一行"在几天之后，那种情况下开盘买入不可执行 |
| 切分 | walk-forward：训练 750 日 / 测试 60 日 / 步长 60 日 / **embargo 2 日** | 标签跨 2 个交易日，训练集末尾不砍掉 2 天 = 标签泄漏（不是特征泄漏，审查特征列查不出来） |
| 可交易性 | 流动性 + 真实上市天数 + ST 代理 + 交易日连续性 + t+1 涨停买不进 + 卖出日跌停卖不出 | 过滤掉的是"有信号但买不到/卖不掉"的行，不这么做的回测是纸上收益 |
| 成本 | 佣金 2.5bp/边 + 过户费 0.1bp/边 + 印花税 5bp（**仅卖出**）+ 半价差 5/10/20bp 三档 | 印花税只在卖出侧收；滑点无法获取盘口数据，只能做敏感性分析 |
| 截面标准化 | 按**日期**分组做 z 分数；市场级特征用 expanding 窗口 | 用全样本均值方差标准化 = 把未来截面信息泄漏进每一行，最隐蔽的一类泄漏 |
| 评价 | RankIC / IC_IR / 普通 t / **Newey-West t** / Bootstrap CI / Deflated Sharpe / 净值·回撤·Sharpe·Calmar | 日频标签跨期重叠，普通 t 值系统性虚高；只在多个变体里挑最好的那个 = 多重检验，必须修正 |

## 四、结果

### 4.1 真实数据（中证 500 + 样本期内退市股）

> 698 只股票（500 只当前成分 + 198 只样本期内退市）· 803,540 行日线 · 2021-01 ~ 2026-09。
> 行情数据未随仓库提供（体积与授权原因），下列数字来自本框架的同一套口径。

**主结果（全部外样本）**

| 变体 | RankIC | IC_IR | 日均毛超额 | 日均换手 | 扣费后净值 |
|---|---|---|---|---|---|
| A 旧特征 + 旧口径 | 1.355% | 0.090 | +0.0776% | 71.2% | 0.757 |
| B 旧特征 + 严格可交易性过滤 | 1.105% | — | +0.0686% | — | 0.772 |
| **C 新特征 + 严格口径** | **1.688%** | **0.096** | **+0.0942%** | **68.3%** | **0.896** |
| 宇宙等权（基准） | — | — | — | — | **1.821** |

**成本敏感性：这才是死因**

| 半价差假设 | 整仓换一遍成本 | 日均成本 | 扣费后年化超额 |
|---|---|---|---|
| 5bp | 0.202% | 0.138% | **−10.4%** |
| 10bp | 0.302% | 0.206% | **−24.5%** |
| 20bp | 0.502% | 0.343% | **−46.4%** |

换手 68%/日 × 每次 0.2~0.5% = 每天 0.14~0.34% 的成本，而信号只有 0.094%/日的毛超额。**成本是毛收益的 1.5~3.6 倍，且三档假设下全部为负 —— 策略在任何合理的成本水平下都不成立。**

**生存偏差：不修正的话 IC 会翻倍**

| 宇宙构造 | RankIC |
|---|---|
| 只用当前中证 500 成分股（常见做法） | **3.25%** |
| 纳入样本期内退市的 198 只股票 | **1.36%** |

同一套特征、同一套过滤，唯一区别是要不要把退市股放回来。**多出来的那一半 IC 完全是"死掉的股票不会说话"造成的。**

**持有期扫描（Newey-West t 值）**：K=5 / 10 / 20 日的 NW t 分别为 1.54 / 1.96 / 1.46 —— 都在显著性边缘，且 K=10 是扫出来的最优值，Deflated Sharpe 修正后进一步走弱。

### 4.2 合成数据 demo（可复现，CI 里每次都跑）

demo 用**人为植入的弱反向动量信号**（信噪比可调）验证流水线能把它检出来 ——
检出已知信号是评估框架的最低要求。默认参数下（160 只 × 1100 交易日）：

| 指标 | 值 |
|---|---|
| 外样本天数 / 折数 | 480 天 / 8 折（正 IC 折 8/8） |
| RankIC | 2.636%（IC 普通 t 6.06 / **NW t 6.02**） |
| 头部组日均毛超额 | 0.0797%，Bootstrap 95% CI [0.0217%, 0.1395%]，p=0.003 |
| 日均换手 / 日均成本 | 69.1% / 0.2053% |
| 扣费后日均超额 | **−0.1256%**（年化 −27.1%，Sharpe −2.95） |
| 随机选股对照 | 随机超额均值 0.0004%，策略 100% 分位，p<0.001 |

**合成数据上复现出了和真实数据完全一致的结论形状**：信号能被检出且显著，但日频换手 69% 让成本吃掉全部收益。完整报告见 [`docs/demo_report.md`](docs/demo_report.md)，逐日明细见 [`docs/demo_daily.csv`](docs/demo_daily.csv)。

## 五、审计：我在自己上一版实现里找到并修掉的 11 个缺陷

这一版之前有一版跑得出"结论"的实现（Windows 上跑脚本 + 手工传数据那种）。我用一个独立的审计流程对着代码逐行核对了它，找到 11 个问题并在本框架里全部处理。**这部分是能力的直接证据：能对自己的结果下狠手，比多写 10 个特征更值钱。**

| # | 缺陷（上一版） | 后果 | 本框架的处理 |
|---|---|---|---|
| 1 | `days_listed` 用 `groupby.cumcount()` 冒充上市天数，抓好的 `上市日期` 列从未被消费 | 2021 年前上市的老股票前 250 行被当"次新"整片剔除（17.4 万行 / 22%）；**换数据起始日重跑，样本集整体平移 → 结论随数据切片漂移** | `panel.attach_listing_dates()` 优先消费真实上市日期，退化路径显式写入 `days_listed_source` 列供审计；3 个专项测试 |
| 2 | 宇宙 = "今天的成分股 + 全部退市股" | 两种反向偏差混合，不对应任何真实可投资池 | 宇宙由面板自带的 `is_delisted` / `listing_date` 定义，支持逐日资格判定；偏差本身需历史成分数据才能消除，已列入局限 |
| 3 | 用 `fwd_ret.notna()` 筛样本 | 退市/停牌导致"无后续报价"的行被整行删掉，**等于用未来可得性筛样本**，系统性高估收益、低估尾部风险 | `fwd_missing_reason` 把缺失分成 `panel_end` / `halted` / `no_quote_after` 三类并单列计数（见报告第 6 节） |
| 4 | 主结果只报点估计，IC_IR 未做重叠修正 | 标签跨 2 日 ⇒ 日频 IC 自相关 ⇒ 显著性被高估 | 普通 t 与 Newey-West t 并列报告；测试断言"重叠序列的 NW t 必须低于普通 t" |
| 5 | 涨跌停价用**后复权价**算，且 `round()` 是银行家舍入 | 除权日复权因子跳变、以及 1 分钱边界上判错涨停/跌停 | `round_half_up()`（交易所是四舍五入，不是舍入到偶）+ 文档要求用不复权价判限价 |
| 6 | 报表候选清单过滤 3 项，回测过滤 6 项 | 报表里"剩 N 只"包含了根本买不进的票 | 全仓库唯一的 `tradable` 定义，报表与回测同源 |
| 7 | K>1 持有期实验的卖出侧仍只校验 t+2 | K=20 时**卖出日的跌停从未被校验**，净收益偏乐观 | `holding_days=h` 参数把跌停校验落在真正的卖出日 t+1+h；embargo 要求同步变成 h+1 |
| 8 | "t 值 1.5~2.0"硬编码在 6 个文件的文案里 | 数字与代码解耦，改了一处忘了另一处 | 所有指标只有一处产出（`metrics.py` + `pipeline.py`），报告由 `report.py` 生成，不存在手抄数字 |
| 9 | 无依赖锁定 / 无 CI / 无测试 / 69 处硬编码绝对路径 / 模块 import 即写盘 | 换台机器就跑不起来；无法证明任何数字 | `pyproject.toml` + GitHub Actions + 58 测试 94% 覆盖 + 零绝对路径 + 无模块级副作用（`import` 不碰文件系统） |
| 10 | `has_t1/has_t2` 只判"存在下一行" | 跨停牌的样本被当成可交易（约占 0.07%），方向上是高估可交易性 | 按市场交易日历严格判定；测试里专门构造停牌股，并记录"单只股票的日期集合不构成交易日历"这个坑 |
| 11 | 特征工程有三份重复实现，且自检只比部分列，换不住漂移 | 训练口径与线上打分的口径会慢慢分叉 | 唯一的 `build_labeled_panel()` 入口；AST 级静态检查禁止 labels.py 之外出现 `shift(-n)` 与 `rolling(center=True)` |

## 七、已知局限（不写这一节的量化项目不值得看）

1. **时点成分股不可得**：退市股已纳入，但指数历史成分需要付费数据源；宇宙仍是"当前成分 + 退市股"的近似。
2. **ST 是代理不是公告口径**：用 5% 停板特征推断，会有漏判与误判。
3. **滑点是假设**：没有盘口/逐笔数据，5/10/20bp 三档做的是敏感性而不是精确复现；真实值与资金量、冲击成本相关。
4. **未做行业/市值中性化**：模型可能部分在赌行业轮动与小市值，这部分收益不稳健。
5. **未建模涨停板排队与冲击成本**：开盘价成交的假设在极端行情下偏乐观。
6. **合成数据不代表市场**：demo 的信号是人为植入的，它验证的是"框架能不能检出已知信号"，不是"策略能不能赚钱"。
7. **未做组合优化**：头部组等权、无风险模型、无仓位管理；这些都会改变净收益，但不改变"成本 > 毛收益"的结论方向。

## 八、用真实数据跑

```bash
# 目录结构（每只股票一个 CSV：日期,开盘,收盘,最高,最低,成交量,成交额,换手率）
# data/
# ├── bars/{code}.csv          当前成分股
# ├── bars_delist/{code}.csv   样本期内退市股
# └── alt/listing_dates.csv    上市日期（强烈建议提供，缺失时会退化并标记）

make report DATA_DIR=data LISTING_CSV=data/alt/listing_dates.csv
# 等价于
afl eval --data data --listing-csv data/alt/listing_dates.csv \
    --train-days 750 --test-days 60 --step-days 60 --holding-days 1 \
    --half-spread 10 --simulations 300 --trials 6 \
    --out output/real_data_report.md
```

